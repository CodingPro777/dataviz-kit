# Chart selection

Choose by question:

- One important value: KPI or stat tile.
- Compare categories: sorted horizontal bar chart.
- Rank categories: ordered bars or dot plot.
- Distribution: histogram, box plot, violin plot, or strip plot according to sample size and audience.
- Change over time: line chart; use area only when accumulated volume matters.
- Two numeric variables: scatter plot.
- Part-to-whole: stacked bar; use a pie/donut only for a few categories and rough proportions.
- Deviation around a target: diverging bar.
- Range or uncertainty: interval or error-bar plot.
- Matrix relationship: heatmap with numeric labels when exact values matter.
- Geographic pattern: map only when location itself explains the pattern.
- Many small time series: small multiples.
- Different units: separate aligned panels or normalize to an index.

Prefer a table when exact lookup matters more than pattern recognition.
