# Color and accessibility

Assign color by role:

- Categorical: distinct fixed colors for identity. Keep assignments stable.
- Sequential: one hue from light to dark for magnitude.
- Diverging: two poles around a meaningful neutral midpoint.
- Status: reserved semantic colors paired with text or icons.
- Highlight: one accent; render context in neutral tones.

Checks:

- Normal text contrast target: 4.5:1.
- Large text and graphical object contrast target: 3:1.
- Use direct labels, shapes, line styles, texture, or position so color is never the only cue.
- Validate light and dark themes independently.
- Avoid rainbow scales unless the domain has a conventional cyclic meaning.
- Limit categorical palettes; group a long tail into Other or use small multiples.
- Respect forced-colors and prefers-reduced-motion where the medium supports them.
- Include a table or textual summary for nonvisual access.
